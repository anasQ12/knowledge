# اعرف نفسك — اختبار الشخصية

موقع من صفحة واحدة: اختبار «اعرف نفسك» (٤ أقسام، ٥٦ سؤالًا).

- `index.html` — صفحة الاختبار (الصفحة الرئيسية)
- `css/style.css` — التنسيقات
- `js/questions.js` — الأسئلة والنتائج (الملف الذي تعدّله)
- `js/translations.js` — نصوص الواجهة
- `js/quiz.js` — منطق الاختبار

للنشر: احذف كل ملفات المستودع القديمة وارفع محتويات هذا المجلد كما هي (مع مجلدي css و js).
